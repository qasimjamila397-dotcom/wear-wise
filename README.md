# WearWise

A wardrobe styling web app. Your clothes stay on your device. Stage 1: setup, branding, Home screen.

## Publish on GitHub Pages
1. Upload these files to your public `wear-wise` repository (not the `node_modules` or `dist` folders).
2. On GitHub: Add file > Create new file. Name it `.github/workflows/deploy.yml`
   (type the slashes and GitHub makes the folders). Paste in everything from `deploy-workflow.txt`. Commit.
3. Repository Settings > Pages > Source: choose "GitHub Actions".
4. Open the Actions tab and wait for the green tick. Your site: https://YOUR-USERNAME.github.io/wear-wise/
